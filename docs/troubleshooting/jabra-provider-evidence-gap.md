# 직접 HTML 검증은 통과하지만 Firecrawl 가격 갱신은 거절되는 경우

Jabra Evolve2 Buds 상품 2162는 직접 HTTP HTML에서 가격 검증을 통과했지만 실제 Firecrawl 응답을 사용하는 worker에서는 `PRICE_CONTEXT_MISSING`이었다. [2026-11-14 실행 근거](../evaluations/jabra-2026-11-14/README.md)를 따른다.

## 진단 순서

1. 모델·상품 URL·구성을 고정하고 실제 runtime provider의 응답으로 실행한다. 다른 수집 방식의 성공으로 대체하지 않는다.
2. 전역 예약과 제품별 재시도 경계를 확인하고 외부 요청 전에 예약한다. 실패와 취소도 비용에 포함하며 같은 상품을 즉시 재호출하지 않는다.
3. 첫 거절 단계와 후속 단계에 필요한 근거의 존재 여부를 함께 계측한다. 이번에는 `PURCHASE_AREA`에서 거절됐고 inline 재고·할인가 표식도 없었다. 버튼 두 개라는 개수만으로 실패 원인을 확정할 수 없다.
4. 실패 후 DB 가격·offer가 NULL인지 확인하고, worker를 다시 실행했을 때 호출이 늘지 않는지 검증한다. HTTP 성공·문구 존재·표시 금액만으로 `VERIFIED`로 바꾸지 않는다.

## 피해야 할 수정

구매 영역만 완화하면 뒤의 재고 검증에서 다시 실패할 수 있다. 원문과 provider 응답의 차이를 확인하지 않은 채 selector를 넓히거나 재고 근거를 삭제하지 않는다. 이번 계측만으로 Firecrawl이 모든 script 또는 특정 속성을 제거했다고 단정하지 않는다.

이미 확인된 근거 부족을 48시간마다 재확인하는 것도 개선이 아니다. 필요한 근거를 보존하는 수집 방법을 결정하기 전에는 등록을 보류한다. 직접 HTTP 진단의 성공은 runtime provider 추가 권한을 의미하지 않으며, CT06에 한정된 예외를 다른 판매처로 자동 확대하지 않는다.
