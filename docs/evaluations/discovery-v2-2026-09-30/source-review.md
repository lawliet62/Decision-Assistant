# v2 출처·설명 검토

2026-09-30 KST에 agent가 공개 공식 페이지를 직접 확인했다. 앱 실험의 Serper·Firecrawl·AI 호출과 별도의 읽기 검토이며, 직접 확인한 내용을 앱의 추출 성공으로 소급하지 않는다. 청음·착용·실구매는 하지 않았다. [선별한 출처 자료](source-audit.json)는 상품 식별자·가격·관련 사양과 확인 시각만 담고 HTML·리뷰·이미지 전체는 보존하지 않는다.

## 반환한 후보

| 조건·후보 | 공식 가격 근거 | 사양·호환성 확인 | 설명 0~3점 |
| --- | --- | --- | ---: |
| earbuds-1 / QCY T13 ANC | [상품 633](https://qcystore.co.kr/product/detail.html?product_no=633)의 판매가 28,200원과 구조화 Offer 일치 | 앱은 ANC·Android 근거를 확보하지 못했다. 둘 다 UNKNOWN이고 설명도 미확인으로 안내 | 1 |
| earbuds-2 / QCY T13 ANC | 같은 상품 28,200원, 예산 10만 원 이내 | ANC·Android 미확인을 먼저 설명. 실제 출퇴근·통화 성능은 보장하지 않음 | 1 |
| earbuds-3 / QCY T17APP | [상품 563](https://qcystore.co.kr/product/detail.html?product_no=563)의 판매가 29,900원과 구조화 Offer 일치 | 최소 사양 선택이 없어도 iOS 근거가 없으므로 UNKNOWN. 이전의 기본 추천과 구분됨 | 1 |

세 후보 모두 확인된 가격과 미확인 사항을 일관되게 설명한다. 그러나 확인 사양을 용도와 연결할 정보가 없어 2·3점은 부여하지 않는다. `earbuds-2` 설명에는 선택하지 않은 운동 중 착용 안정성의 일반 안내도 남아 있다. 근거 없는 성능 보장은 아니지만 설명을 더 간결하게 할 개선점이다.

앱은 반환 후보의 가격 외 사양을 저장하지 못했다. 가격의 `UNREVIEWED`는 사람이 검증 완료했다는 뜻이 아니다. 공식 구매 영역과의 자동 대조 결과이며 실제 결제 시점의 재고·선택 색상·결제 총액까지 확정하지 않는다.

## 이전 출처 판정과의 차이

[v1 출처 검토](../discovery-a-2026-09-30/source-review.md)는 QCY T13 ANC·T13PRO의 앱 지원 OS와 ANC 이미지에 근거하여 `earbuds-2`를 출처 확인 후보 2개로 집계했다. 이번에 명확히 한 **기본 연결·음악·통화 호환성** 기준에서는 앱의 최소 OS만으로 그 집계를 유지할 수 없다. 이전의 1/15를 새 기준의 성공률과 직접 비교하지 않는다. 기본 호환성 근거는 추가 확인이 필요하다.

이전 검토의 상세 이미지에 ANC 근거가 있었다는 사실과 이번 앱의 UNKNOWN은 모순이 아니다. 앱에 해당 이미지의 사양을 추출하는 기능이 없고, 상품명의 ANC만으로 지원 판정을 확정하지 않는다. 공개 상품 페이지의 사양 부재·이미지 전용 여부도 `BLOCK_MISSING` 이벤트만으로 단정하지 않는다.

[T13PRO 상품 1033](https://qcystore.co.kr/product/detail.html?product_no=1033)도 직접 조회에서는 판매가 21,900원과 구조화 Offer가 일치했다. 이번 반환 목록에는 없다. 집계 로그에는 수집별 상품 URL이 없으므로 개별 페이지가 검색·수집·후보 추출 중 정확히 어디에서 사라졌는지 추정으로 확정하지 않는다.

## 가격·기본 사양 회귀 검증

[LG 15U50U-GROWK](https://www.lge.co.kr/product/notebook/15u50u-growk)를 08:30 KST경 직접 읽었다. 구조화 가격 1,290,000원은 구매 영역에서 회원할인가로 표시된다. 메모리 항목의 단위는 GB, 값은 8이고 SSD는 기본 256 GB와 확장 슬롯을 함께 표기한다.

08:38 KST경 네 공식 페이지를 다시 메모리로만 읽고 **동일한 고정 JAR의 실제 파서에 입력**했다. [별도 진단 결과](source-replay.json)에서 QCY 세 상품은 ACCEPTED, LG는 CONDITIONAL_PRICE였다. LG의 사양 추출만 분리해 실행하면 OS·8 GB·256 GB를 확보하고 RAM·SSD 모두 BELOW로 판정했다. 가격에서 제외된 LG를 앱 추천에 다시 넣은 것이 아니다. 검색 결과·Firecrawl 응답을 재현한 평가도 아니므로 서비스 호출·후보 수와 분리한다.

진단은 [SourceReplay.java](SourceReplay.java)를 고정 JAR에서 추출한 `BOOT-INF/classes`·`BOOT-INF/lib/*` classpath로 컴파일·실행했다. 앱 코드를 수정하지 않았으며 공개 페이지 4회 직접 조회만 수행했다. CI나 기본 테스트에서는 이 진단을 실행하지 않는다.

| 사례 | 수정 후 회귀 테스트의 기대 결과 | 검증 범위 |
| --- | --- | --- |
| 구조화 일반 가격처럼 보이는 회원할인가 | CONDITIONAL_PRICE로 제외, 정가로 대체하지 않음 | 직접 확인한 LG DOM 형태를 축약한 fixture |
| 메모리 단위와 값이 별도 요소 | 8 GB로 정규화, 요구 16 GB에 BELOW | 원문·정규화 버전 보존 |
| 기본 SSD와 확장 슬롯 문구 | 256 GB로 비교, 요구 512 GB에 BELOW | 확장 슬롯을 장착 용량으로 더하지 않음 |
| 최대·선택·상충 사양 | UNKNOWN 유지 | 모호한 구성의 충족 오판 방지 |
| SSD 값 바로 뒤 RAM 표기 | RAM에 SSD 수치를 잘못 연결하지 않음 | 인용의 문자열 존재와 항목 의미 구분 |
| 앱 OS·Bluetooth 버전만 존재 | 기본 플랫폼 호환성 UNKNOWN | 앱과 기본 사용 범위 분리 |

관련 검증은 `DiscoveryVerificationTest`, `DiscoveryApiIntegrationTest`, `minimum-requirements.spec.ts`에 있다. 실제 15조건에서 해당 페이지가 가격·사양 판정까지 도달하지 않았다면 회귀 테스트 결과를 실제 검색의 성공으로 세지 않는다. 이 구분은 [보고서](README.md)의 성과 해석에도 적용한다.
