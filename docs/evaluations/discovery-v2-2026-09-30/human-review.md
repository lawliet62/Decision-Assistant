# 사용자 직접 평가표

[v2 평가 보고서](README.md)와 [agent의 출처·설명 검토](source-review.md)를 참고하되 아래는 사용자 평가를 남길 빈 양식이다. Agent 평가를 사용자 평가로 복사하지 않는다. [고정 15조건](../../../scripts/discovery-evaluation/cases.json)과 [공통 평가 기준](../../discovery-evaluation.md)을 사용한다.

후보 수는 공식 상품·조건 없는 가격·예산·최소 사양·필요한 호환성까지 근거를 확인한 서로 다른 모델만 센다. 이어폰 앱의 최소 OS 버전만으로 기본 음악·통화 호환성을 확인했다고 기록하지 않는다. 미확인과 명시적 미지원을 구분한다. 후보가 없으면 설명 점수는 해당 없음이다.

설명 점수: 0 근거 없음, 1 사양 반복·일반론, 2 확인 사양과 용도의 연결, 3 연결 설명과 한계·미확인 사항 제시. 미확인을 잘 고지한 것만으로 3점을 주지 않는다.
