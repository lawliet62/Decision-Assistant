# 재실험 후보의 출처 검토

2026-09-30 KST에 agent가 공식 상품 페이지, 그 페이지가 직접 포함한 상세 이미지, 상품 구조화 데이터를 읽었다. 가격·객관 사양 확인이며 청음·착용·벤치마크 결과가 아니다. 직접 확인한 사양을 앱이 추출한 사양으로 소급하지 않는다. 상세 이미지 원문은 보고서에 복제하지 않고 URL과 필요한 짧은 문구만 남긴다.

가격 확인 시각은 각각 07:14, 07:10, 07:16경이다. QCY 1033·563은 web 읽기 도구에서 cache miss가 발생해 동일 공개 URL을 직접 HTTP 조회했다. 모두 응답 200이며 해당 상품의 ProductGroup/Offer를 확인했다. 633의 구조화 색상명에는 부모 상품명과 variant의 불일치가 있어 구매 시 색상 확인이 필요하다. 비교 수에는 색상을 별도 모델로 세지 않는다.

인용 확인 문구: 633 이미지의 `안드로이드 6.0 이상 / iOS 12 이상`, 1033 앱 이미지의 `8.0이상 안드로이드`, 1033 규격 이미지의 `ANC 기능 ON`. Android의 구체 버전은 사용자 입력에 없으므로 위 최소 버전 이상에서의 지원으로 평가한다. 장치별 호환성 전체나 주관적 용도 적합성을 보장하는 판정은 아니다.

`earbuds-2`의 두 모델은 서로 다른 제품이고 예산 10만 원 이하·ANC·Android의 객관 근거가 있어 출처 검토상 비교 가능 후보 2개로 센다. 그러나 앱이 제시한 근거만으로는 ANC를 확인할 수 없다. `earbuds-1`은 같은 방식으로 확인한 후보가 1개다. `earbuds-3`은 iOS 근거를 미확인으로 남긴다.

## 노트북

[LG 15U50U-GROWK 공식 페이지](https://www.lge.co.kr/product/notebook/15u50u-growk)의 제품 스펙과 가격 표시를 07:11~07:15경 확인했다.

- 기본 RAM은 8GB, SSD는 256GB다. `laptop-1`의 16GB·512GB 조건에 둘 다 미달한다. 확장 슬롯이나 추가 장착 가능 용량을 기본 구성으로 간주하면 안 된다.
- Windows 11 Home과 Core Ultra 5 115U는 확인된다. AI 설명의 CPU 표기는 출처와 맞지만, 메모리·저장공간 미달은 설명하지 않는다.
- 구조화 Offer와 앱 가격은 1,290,000원이다. 동일 페이지의 가시 가격 영역에는 이 금액을 **회원할인가**로 표시하고 할인 전 판매가는 1,550,000원으로 안내한다. [현재 정책](../../official-stores.md)은 회원·조건부 가격을 제외하므로, 조건이 구조화 Offer 필드에 없을 때 가격 파서가 이를 통과시키는 문제가 확인됐다. 회원 조건을 확인하지 않은 채 예산 150만 원 이내라고 확정할 수 없다.
- 앱은 RAM·SSD를 충족 처리하지 않고 둘 다 `UNKNOWN/MISSING`으로 남겼다. 따라서 **필수 사양의 충족 오판은 아니지만, 실제 미달 후보를 미확인으로 남긴 사례**다.
- 앱이 인용한 39.6cm/16인치 표현은 공식 metadata에도 존재한다. 단위 환산과 맞지 않는 표현을 곧바로 AI가 만들어낸 사실로 분류하지 않고 원출처의 일관성 문제로 구분한다.
