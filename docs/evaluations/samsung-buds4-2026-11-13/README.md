## 검증 범위

다중 모델 ProductGroup 전체를 한 제품으로 취급하지 않는다. 화이트 SKU의 Offer와 실제 선택 모델·색상·수량, 일반 혜택가·총액을 연결한다. 알려진 다른 canonical 주소도 이 SKU의 고정 별칭만 인정한다. 최대 혜택가를 단독으로 일반 가격으로 사용하지 않고 즉시 할인 산식과 카드 미적용 상태를 확인한다.

즉시 할인이 있으면 공개 행사 기간이 하나로 특정되고 확인 시점부터 72시간 전체를 포함해야 새 가격을 수용한다. 행사 종료 임박·기간 누락·서로 다른 기간은 보류한다. 가격 자체가 그 기간 동안 변하지 않는다고 보증하는 규칙은 아니다.

사양의 OS 독립 문구는 Android/iOS **기본 블루투스 오디오 연결**만 뜻한다. 앱·고급 설정의 Android 버전·메모리 조건을 기본 연결과 합치지 않는다. 이 대응은 등록 카탈로그의 정확한 모델·출처·인용에만 적용하고 일반 실시간 탐색이나 앱 지원으로 확대하지 않는다.

## 수집 표현과 비용

Java 직접 조회는 HTTP 200이고 사양 문단을 포함하지만 동적 가격 상세는 없었다. 렌더링 후에는 HTML 1,954,879자·2,145,941바이트를 관찰했다. 이 고정 SKU의 가격 HTML만 300만 자로 제한하고 다른 상품의 200만 자 제한은 유지한다. 처음 사용한 오프라인 진단 CLI의 200만 바이트 제한 실패와 실제 파서의 문자 수 제한을 구분했다.

수량 input의 HTML attribute는 빈 값이지만 현재 property와 접근성 알림 `buy_count_status`는 1이었다. input 값을 강제로 바꾸지 않고 문서에 직렬화되는 수량 알림과 단가·총액을 함께 검증한다. Firecrawl은 대기 후 단일 snapshot만 사용하고 초기 rawHtml로 대체하지 않는다.

실제 Firecrawl 요청 1회, 개발 DB 월 계수 76→77, 잔여 credit 996→995였다. 사양은 추가 AI 호출 없이 기존 Java HTTP 경로를 사용했다. 구매·충전·운영 리소스 생성은 없었고 실제 청구액은 확인하지 않았다. 원문 HTML·키·사용자 정보는 저장하지 않았다.

48시간 이후 반복 안정성과 운영 활성화는 아직 검증하지 않았다. [진단 기록](../../troubleshooting/samsung-selected-price-and-basic-audio.md)을 함께 참고한다.
