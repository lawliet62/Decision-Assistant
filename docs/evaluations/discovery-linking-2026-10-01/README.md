## 5. 설명 유용성과 다음 순서

반환한 7개 설명 모두 **1/3점**, 평균 1.0점이다. 직전 3개 설명도 평균 1.0점이었다. 가격·예산·미확인 안내는 일치하지만 확인 사양을 용도에 연결한 2·3점 설명은 없다. 후보만 늘었으며 설명 품질이 개선됐다고 주장하지 않는다.

이번 우선순위는 추가 호출이나 새 provider 없이 정상 상품 탈락을 줄이는 것이었다. HT16·HT19 복구와 색상 중복 제외를 같은 원문·회귀·실제 서비스 실행에서 확인했으므로 유지할 가치가 있다. 다만 MVP의 추천 품질 목표를 달성한 상태는 아니다.

남은 작업은 B/C라는 이름보다 다음 병목 순서로 설계한다. 먼저 **정확한 모델의 공식 사양 근거를 확보하는 제한적 보완 검색**을 검토한다. 상품명·앱 지원 OS를 기본 호환성으로 확대 해석하지 않고 동일 모델의 설명서·지원 문서와 구매 페이지를 연결해야 한다. B의 AI 계획을 도입하더라도 이 근거 확보와 공식 개별 상품 URL 도달을 목표로 해야 하며 질의를 여러 개 생성하는 것만으로 설명은 좋아지지 않는다. C의 리뷰 탐색은 착용감·통화 품질 등 주관적 근거가 필요할 때 후속으로 검토하되, 현재는 구현하지 않는다. 추가 호출 상한·다른 문서의 동일 모델 연결·데이터 계약은 별도 설계 대상이고 이번 결과로 비용 대비 이득을 입증했다고 보지 않는다.
