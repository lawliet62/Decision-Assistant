# 주류 이어폰 후보의 독립 출처 점검

2026-11-13 첫 조사 이후 공개 공식 페이지를 직접 조회하고, 기존에 설치된 Playwright의 격리 브라우저로 소니 상품을 점검했다. 로그인·주문·장바구니 조작은 하지 않았고 원문 HTML·브라우저 프로필·키는 저장하지 않았다. 이번 후속 점검에서는 OpenAI·Firecrawl API를 추가 호출하지 않았다. 개발 DB의 조사 슬롯은 기존 세 건 그대로다.

## Samsung: 새 구매 주소에 데이터가 있지만 가격 검증은 미완료

[버즈4 화이트의 기존 상품 주소](https://www.samsung.com/sec/buds/galaxy-buds4-r540/SM-R540NZWAKOO/)는 직접 요청에서 HTTP 302를 반환했다. [새 구매 주소](https://www.samsung.com/sec/buds/galaxy-buds4/buy/?modelCode=SM-R540NZWAKOO)는 HTTP 200, 약 1.34MB였으며 모델 SKU를 포함했다. canonical은 기존 상품 주소를 가리켰다.

새 응답의 JSON-LD에는 버즈4와 버즈4 프로, 색상을 함께 담은 ProductGroup이 있었다. 화이트 SKU `SM-R540NZWAKOO`의 Offer 금액과 구매 영역 하단 표시 금액은 220,200원이었다. 하지만 화면에는 최대 혜택가·카드 조건 안내가 있고 여러 모델·색상도 함께 제공하므로 무조건 구매 가능한 가격으로 검증하지 않았다. 기존 파서의 canonical 대조와 단일 구성 검증도 그대로 통과한다고 가정하지 않는다.

같은 공식 페이지에서 버즈4의 ANC 지원과 OS와 관계없는 블루투스 오디오 연결 설명을 확인했다. 앱·고급 설정은 Android 조건과 삼성 계정이 별도로 필요하며 기본 연결과 구분해야 한다. 사양 근거를 찾을 수 있다는 사실과 활성 카탈로그 등록은 별개다.

## Sony: HTTP 본문과 렌더링 결과를 구분

[기등록 Float Run 주소](https://store.sony.co.kr/product-view/109871591)의 직접 응답은 HTTP 200, 3,448바이트였으나 상품 구매 영역이 없는 JavaScript 앱 셸이었다. 격리 브라우저에서는 같은 최종 URL, 모델명, 구매 영역 한 개를 확인했다.

렌더링 결과의 `.product_price .original .price`는 169,000원, `.product_price .sale .price`는 159,000원이었다. 주문 경로를 가진 구매 링크도 있었으나 총 상품금액은 아직 수량·금액이 선택되지 않은 표시였다. 과거 [옵션 선택 및 Firecrawl 점검](../catalog-2026-10-29/README.md)의 제약을 해소한 것으로 보지 않는다. 기존 Firecrawl 응답이나 가격 worker가 이번 브라우저와 같은 데이터를 반환한 것은 아니다. 비활성 상태를 유지한다.

공개 앱의 상품 조회 호스트도 확인했지만 플랫폼 API 사용 권한·한도·재사용 조건은 추가로 확인되지 않았다. 상점 식별자나 인증 정보를 저장하거나 새 API provider로 등록하지 않았다.

## JBL: 조사 허용 도메인 누락 수정

[JBL 한국 공식 사이트](https://kr.jbl.com/)는 직접 요청에서 HTTP 200이었다. [공식 한국 고객지원](https://support.jbl.com/kr/kr/)의 스토어 링크도 이 주소로 연결된다. 반면 조사 설정에는 `jbl.co.kr`과 `samsung.com`만 있어 공식 한국 제품·지원 출처를 빠뜨렸다.

JBL 조사 도메인을 `kr.jbl.com`, `support.jbl.com`, `samsung.com`으로 정정하고, 허용한 도메인과 유사한 외부 호스트를 거절하는 회귀 테스트를 추가했다. 요청 설정 변경을 구분하도록 새 실행의 prompt 버전을 `catalog-official-research-v2`로 올렸다. 기존 세 실행은 v1 기록을 유지한다.

이 누락이 첫 조사의 모든 UNKNOWN이나 실패를 설명한다고 단정하지 않는다. 제조사 제품 페이지와 고객지원 페이지는 사양 출처가 될 수 있지만 실제 국내 구매 URL·가격·재고는 별도로 검증해야 한다. 도메인 수정 후 유료 API 재실행은 하지 않았고 제품을 추가 활성화하지 않았다.

## 다음 검증에 필요한 근거

- Samsung은 선택 SKU·모델·색상, canonical 별칭, 무조건 판매가와 혜택가를 각각 구분한 검증이 필요하다. 모델 전체를 같은 가격으로 묶지 않는다.
- Sony는 실제 수집 응답에서 단일 구성과 구매 금액을 연결해야 한다. 브라우저 관찰만으로 수집 성공으로 기록하지 않는다.
- JBL은 정정한 공식 출처에서 모델·국내 구매 경로·사양을 연결한 뒤 활성화를 판단한다.

활성 상품은 기존 7개 브랜드·22개다. 가격·사양 자동 갱신과 주류 제품 확대 목표는 여전히 미완료다.
