# OpenAI 공식 출처 조사 첫 실행

2026-11-13 개발 DB와 Dev Secret Manager를 사용해 Samsung·Sony·JBL 조사를 각각 한 번 수행했다. 사용자 결정·조건·메모는 전달하지 않았고, 카탈로그나 검증된 가격·사양은 변경하지 않았다. 처음 실행 전 OpenAI Secret 버전 누락으로 bootstrap이 중단됐으며, 활성 버전 메타데이터만 확인해 프로세스에 전달한 뒤 기존 JVM 로더로 키를 읽었다. 키는 출력·저장하지 않았다.

| 조사 | 결과 | 확인된 사용량 | 한계 |
| --- | --- | --- | --- |
| Samsung | FAILED_OR_USAGE_UNKNOWN | 미확인 | 첫 실패에서 상세 사유·사용량을 수집하지 못했다. 0회·0달러로 해석하지 않는다. |
| Sony | FAILED_OR_USAGE_UNKNOWN | 입력 12,964·출력 1,827토큰 | API 응답 incomplete. 구체적인 중단 사유는 기록하지 못했다. |
| JBL | PROPOSAL_UNREVIEWED | 입력 9,005·출력 981토큰·검색 3회 | 정확한 가격·ANC·기본 호환성 근거가 없어 UNKNOWN. 가격 검증 성공이 아니다. |

JBL 조사에서 SENSE PRO 오픈 이어 모델 `JBLSENSEPROGRY`와 삼성 국내 공식 상품 URL을 제안했다. 이 제안은 모델과 국내 유통 구성의 독립 검증 전이며 활성 상품으로 등록하지 않았다. 수집 내용과 공식 URL 목록은 개발 DB 조사 기록에 보존한다. API 응답 원문·페이지 원문·자격 증명은 저장하지 않았다.

현재 공개 단가로 입력·출력 토큰과 검색 3회를 계산한 JBL 비용은 약 $0.0412다. 캐시 할인과 계정 청구액을 조회한 결과는 아니며, 첫 두 실패를 포함한 전체 비용은 확정하지 못했다. 계정의 실제 잔여 크레딧도 별도로 조회하지 않았다. 제공된 크레딧 내 API 요청이 처리됐다는 관찰을 잔여 예산 증명으로 해석하지 않는다.

초기 2회 검색·2,000 출력 토큰 제한에서는 완료하지 못한 응답이 있어 이후 3회·4,000토큰으로 조정했다. 상한이 실패 원인이었다고 확정하지는 않는다. HTTP 상태·안전한 오류 코드·미완료 사유와 실패 시 반환된 token 수를 기록하도록 보강했다. 재시작으로 실패를 반복하지 않도록 월 5개 슬롯에 호출 전 예약하고 실패 슬롯을 보존한다. 다음 실행은 사용하지 않은 슬롯을 명시해야 하며 자동 재시도하지 않는다.

이 결과는 OpenAI 웹 검색 경로의 실행 가능성과 한 개의 조사 제안을 확인한 것이다. Firecrawl 대체, 주류 이어폰 데이터 확보, 가격 정확성이나 운영 자동 갱신이 달성됐다는 뜻은 아니다. 다음 단계는 모델·SKU·공식 근거를 독립 검증하고, 비교 가능한 후보를 카탈로그에 등록하는 것이다.
