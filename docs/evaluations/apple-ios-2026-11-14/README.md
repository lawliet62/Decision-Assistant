# Apple iOS 기본 연결 근거 보강

## 문제와 적용 범위

기존 Apple 두 제품에는 ANC·방수만 등록돼 있어 iOS 필수 조건에서 UNKNOWN이었다. AirPods 5와 AirPods Pro 3 각각의 공식 사양 페이지에서 최신 iOS를 설치한 iPhone 요구사항과 이전 소프트웨어의 기본 Bluetooth 사용 안내를 함께 확인했다. 모델 제목·canonical과 단일 요구사항 영역에서 두 항목이 정확히 하나씩 일치할 때 검증한다. 다른 OS 항목 수나 순서는 조건으로 삼지 않는다.

등록 카탈로그의 iOS 기본 연결 판정에만 적용한다. 고급 기능·특정 구형 기기나 iOS 버전·Android 지원으로 확대하지 않는다. 원래 요구사항 인용을 표시하며, 일반 실시간 탐색·분쟁 근거와 모호하거나 상충하는 근거의 UNKNOWN 처리는 유지한다. Android 공식 연결 문서도 조사했지만 이번 단일 출처 근거에는 합치지 않았다. 같은 항목의 별도 출처를 추가할 때는 확인 시각이 서로 잘못 연장되지 않도록 설계해야 한다.

## 확인과 자동 갱신

[출처 관측](sources.json)은 실제 HTTP 200 HTML을 Java 검증기에 입력한 결과이며 원문 대신 hash·결과·시각만 저장했다. 새 SOFTWARE 사양은 30일 수명이고 기존 제품별 주간 worker가 같은 사양 페이지 조회에서 점검한다. 조회 횟수와 예약 주기를 늘리지 않는다. GitHub 출처 점검도 이미 등록된 같은 URL을 사용한다.

두 제품의 revision은 2다. 구매 URL·identity는 유지하므로 기존 가격과 다음 가격 조회 시각은 보존된다. revision 변경으로 이전 fact_reviews는 초기화되며, 기존 하드웨어 근거는 원래 시각을 유지한다. 운영 DB·개발 기본 DB에 이번 manifest를 직접 반영하지 않았다.

## 실제 추천 API

개발 DB의 공개 활성 25개 카탈로그에서 가격 관측만 격리 PostgreSQL에 복사했다. 모든 ID·구매 URL·identity를 대조했고 원래 가격 시각·예약을 SQL JSON으로 보존했다. 같은 revision·사양인 항목만 기존 fact_reviews를 복사했다. 개인 결정·사용자 정보는 복사하지 않았다. 새 코드와 manifest로 실제 Spring Boot를 기동하고 외부 기능을 끈 상태에서 API를 호출했다.

[API 관측](api-results.json)의 iOS·ANC 필수 조건 결과는 다음과 같다.

| 예산 | RECOMMENDED |
| --- | --- |
| 25만원 | QCY T13 Pro 22,900원, Samsung 버즈4 220,200원, AirPods 5 229,000원 |
| 40만원 | 위 세 제품과 AirPods Pro 3 369,000원 |

이전 [통합 평가](../catalog-mainstream-2026-11-13/README.md)의 25만원 조건은 두 후보였다. 현재 같은 조건에서 세 후보를 확인했다. 나머지 사양 미확인 후보는 UNKNOWN을 유지한다. 새 가격을 조회한 결과가 아니며 Apple 가격 시각은 2026-11-13T12:14:46.793786400Z와 12:14:58.509768100Z다. 외부 가격 관측은 0건이고 유료 API 호출도 없다. 임시 결정은 DELETE 204로 모두 삭제했고 서버와 임시 DB도 정리했다.

검증 스크립트에서 삭제 요청의 expectedVersion을 body로 전송해 처음에는 정리가 실패했다. API 계약대로 query parameter로 바꾼 뒤 기존 임시 결정까지 삭제했다. 상품 조회나 가격·사양 검증 실패로 해석하지 않는다.

## 자동 검증과 남는 작업

`npm run check` 전체를 통과했다. 이후 추가한 통합 테스트는 만료된 iOS 근거의 갱신·주간 1회 예약·가격 시각과 예약 보존을 검증했다. 모델·canonical·요구사항 불일치, DISPUTED·Android·일반 탐색 제외도 테스트한다. 실제 장기 주기 반복, 기본 DB 적용, Android 기본 연결 근거 보강은 남아 있다. 전체 카탈로그 자동 운영 목표의 완료를 의미하지 않는다.
