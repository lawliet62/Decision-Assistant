소니 상품 화면이 호출하는 쇼핑몰 플랫폼에는 [공식 상품·옵션 API 문서](https://docs.shopby.co.kr/?url.primaryName=product%2F)와 [호출 안내](https://workspace-help.nhn-commerce.com/aurora-guide/api/shopbyapi)가 있다. 문서는 상품 번호별 옵션 조회와 프론트 화면용 상점 식별자·플랫폼·버전 헤더를 설명한다. 공개 명세의 옵션 응답에는 할인 적용가, 추가금액과 판매 가능 상태 항목이 있다. 별도 브라우저 확인에서 Float Run은 한 옵션과 추가금액 0원, 구매가 159,000원을 반환했지만 이는 해당 시점의 단일 관측이다.

스크립트의 UTF-8 인코딩을 수정하고 가짜 응답에서 정상 처리를 확인한 뒤 한 차례 더 호출했다. 이 응답의 Markdown에는 `구매하기`와 `최대 혜택가` 249,000원 문구가 있었으나, Product JSON-LD에 SKU·Offer가 없었다. 조건부 최대 혜택가와 구매 버튼의 단순 존재만으로 일반 판매가와 구매 가능 상태를 확정할 수 없어 등록은 보류한다. 이 확인은 단일 시점의 수집 응답이며 사이트 전체에 대한 결론은 아니다. 네 번의 호출은 각각 개발 DB 월 예약에 반영해 기존 18회에서 22회가 됐다. 별도 시험 DB에서 기록한 세 번을 포함해 이번 달 관측된 예약은 총 25회이며 계정의 다른 사용량은 확인하지 않았다. 진단 오류는 [troubleshooting](../../troubleshooting/catalog-source-drift.md#진단-스크립트의-인코딩)을 참조한다.

## 젠하이저 한국 공식 스토어 후보

[한국 공식 스토어](https://kr.sennheiser-hearing.com/)의 [MOMENTUM True Wireless 5](https://kr.sennheiser-hearing.com/product/detail.html?product_no=731)를 추가 후보로 조사했다. 직접 HTML의 ProductGroup에는 색상 다섯 개의 SKU와 InStock·동일 가격 429,000원이 명시돼 있고, 상품 화면에는 판매가 429,000원과 별도 최대할인가 399,000원이 있다. 상품 사양에는 ANC와 IP54도 명시돼 있다. 페이지에는 옵션 선택과 품절·구매 문구가 함께 있어 텍스트 존재만으로 실제 구매 가능 여부를 확정하지 않는다.

현재 허용 목록에 이 판매처가 없고, 색상 옵션의 상품 URL·실제 구매 상태·조건 없는 판매가가 기존 가격 검증 경계에 들어오는지와 실제 Firecrawl 응답은 확인하지 않았다. 따라서 후보 조사 결과이며 상품 활성화나 신규 판매처 수집 성공을 뜻하지 않는다. Firecrawl 호출은 추가하지 않았다. 8개 제품을 31일간 매일 조회하면 약 248회로 현재 월 250회 한도의 여유가 작다.

후속 브라우저 진단에서 검정 색상을 선택한 뒤 구매 영역의 표시 가격과 상품 합계는 각각 429,000원이었고 구매 버튼이 보였다. 주문이나 장바구니 요청은 실행하지 않았다. 같은 상품에 대한 Firecrawl 기본 수집 1회에서도 색상 다섯 개의 SKU·InStock·429,000원 및 최종 가격 요소를 확인했다. 두 조회는 독립된 단일 시점 관측이며, 미선택 상태의 Firecrawl 응답만으로 모든 색상의 실제 주문 가능성을 보장하지 않는다. 앱의 판매처별 가격 파서·사양 갱신과 DB 저장은 아직 미구현이다. 호출은 개발 DB에 예약해 22회에서 23회가 됐고 별도 시험 DB의 세 번을 포함한 이번 달 관측 예약은 26회다.

이후 상품 전용 가격 검증을 시험했다. 합성 fixture의 모델·색상·가격·품절·버튼 불일치 검사는 통과했지만 실제 Firecrawl 응답에서는 가격 검증을 통과하지 못했다. 최초에는 같은 구매 버튼 ID가 두 영역에 있어 거절됐고, 브라우저에서 표시되는 기본 구매 영역으로 좁힌 후에도 해당 응답에서 주문 동작 속성을 가진 상위 링크를 확인하지 못했다. 브라우저에는 이 속성을 가진 링크가 보였으나 Firecrawl 응답에서 속성이 제거됐는지 구조가 달라졌는지는 확인하지 못했다. 단순 문구 존재로 구매 가능 여부를 확정하지 않고 시험용 파서는 적용하지 않았다. 추가 Firecrawl 다섯 번은 개발 DB 예약에 반영해 23회에서 28회가 됐으며, 별도 시험 DB의 세 번까지 이번 달 관측 예약은 총 31회다. 실제 계정의 다른 사용량은 확인하지 않았다.

후속 진단에서 Firecrawl 응답의 기본 구매 버튼 상위 요소는 링크였지만 `onclick`이 없고, 원래 `#none` 주소는 해당 상품의 절대 URL로 바뀌었다. 동일 모델의 다섯 색상 SKU·재고·동일 가격, 색상 선택과 표시 가격, 기본 구매 영역의 버튼 및 두 가지 허용 주소를 함께 대조하는 카탈로그 전용 파서를 추가했다. 서로 다른 가격·품절·SKU·옵션·버튼·외부 주소와 조건부 가격을 거절하는 테스트가 통과했고, 마지막 검증 규칙을 적용한 실제 Firecrawl 응답도 429,000원으로 확인됐다. 버튼의 실제 주문 처리나 모든 색상별 주문은 검증하지 않았다. 사양 자동 갱신과 DB 저장이 없어 상품은 아직 등록하지 않는다. 후속 진단 여섯 번을 개발 DB에 예약해 28회에서 34회가 됐고, 별도 시험 DB 세 번까지 이번 달 관측 예약은 총 37회다.

이후 상품 731을 활성 등록하고 ANC와 이어버드 IP54의 자동 재확인을 추가했다. 공식 상품 번호·제품명·사양표 행을 대조하며 IP54의 적용 대상이 이어버드라는 인용을 유지한다. 실제 공식 페이지를 직접 조회한 임시 PostgreSQL 통합 시험에서 두 항목의 확인 시각과 다음 시도 기록이 저장됐고, GitHub 출처 점검 스크립트의 제목·인용 확인도 통과했다. 상품 선택 시 가격을 DB에 저장하는 경로와 사양 일부가 불일치한 경우의 분리 처리는 모의 응답을 사용하는 통합 테스트로 검증한다. 이 시험은 상시 운영이나 실제 주문을 증명하지 않는다. 추가 Firecrawl 호출은 없었다.
