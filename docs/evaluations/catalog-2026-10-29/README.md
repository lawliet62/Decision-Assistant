## 등록 정정과 사양 검토

T13 ANC의 판매 URL은 직접 요청에서도 404였다. 같은 모델의 대체 판매 페이지가 확인되지 않아 revision 2에서 비활성화한다. 기존 사양과 개인 비교는 삭제하지 않는다. HT19는 같은 공식 상품 번호 1012의 구조화 이름이 바뀌었으며 색상 variant 이름도 현재 그룹명에 연결됨을 확인했다. 새 이름과 identity를 revision 2로 등록한다. 수정 이후의 실제 Firecrawl 재시도는 제품별 24시간 제한을 우회하지 않았으므로 아직 검증하지 않았다.

QCY T13 Pro의 공식 페이지에서 제품명·Bluetooth 6.0·기존 ANC·호환성·IPX4 인용을 다시 대조했다. T13 ANC의 글로벌 사양 페이지도 기존 제품명·Bluetooth 5.3·인용을 대조했으나 국내 판매 종료 상태와 분리했다. 이번 agent 검토를 revision과 확인 시각에 반영했다. 미래의 예약 문구 일치가 이 검토를 자동 대체하지 않는다.

Apple은 [현재 구매 페이지](https://www.apple.com/kr/shop/buy-airpods/airpods-pro-3)의 Offer SKU와 단일 구매 선택 링크의 product 값, 해당 링크 내부 가격을 함께 검증한다. [모델별 사양](https://www.apple.com/kr/airpods-pro/specs/)에서 ANC·IP57을 등록했으며 기본 플랫폼 호환성은 명시적인 판정 근거를 등록하지 않아 UNKNOWN으로 유지한다. 이 표의 가격은 실행 당시 관측이며 seed 가격으로 복사하지 않는다.

## 미검증 범위

상시 운영 호스팅·운영 DB·운영 인증·재배포는 아직 확인하지 않았다. 로컬 실행 성공이 PC를 끈 상태의 주기적 실행을 의미하지 않는다. GitHub 예약 실행과 실패 알림 수신도 이번 로컬 점검으로 증명하지 않는다. 삼성 버즈3 FE의 직접 응답은 제품 JSON-LD가 없는 공통 페이지였으므로 삼성 상품 등록은 보류했다. 다른 URL·렌더링된 Firecrawl 응답은 별도 확인이 필요하다.

## 추천 API smoke

정정된 manifest를 재기동으로 반영한 뒤 외부 수집을 끄고 실제 로컬 API를 호출했다. EARBUDS·ANC 필수·예산 500,000원·플랫폼 미선택·모든 외부 동의 false 요청이 HTTP 201을 반환했고, AirPods Pro 3는 RECOMMENDED / VERIFIED / 369,000 KRW로 노출됐다. QCY T13 Pro도 RECOMMENDED / VERIFIED / 24,300 KRW였다. HT19는 가격 미확인, T13 ANC는 비활성으로 새 후보에서 제외됐다. 이는 실제 DB→추천 응답 검증이며 실제 브라우저 렌더링·운영 배포는 포함하지 않는다.

## 추가 실제 수집

같은 날 정정된 HT19는 Firecrawl→DB 갱신 결과 VERIFIED, 48,500 KRW였다. 소니 Float Run은 상품 상세의 DOM 구조를 브라우저에서 확인하고 단일 상품 전용 검증을 추가했지만 실제 Firecrawl 응답의 결과는 PRODUCT_AMBIGUOUS였다. 당시 검사에서는 구매 영역이 없을 때와 여러 개일 때를 같은 코드로 기록했으므로 어느 경우인지는 확인하지 못했다. 이후 사유를 구분하도록 수정하고 상품을 비활성으로 보류했다.

후속 진단에서 기존 월 호출 기록에 예약한 Firecrawl 요청 4회를 추가했다. 기본 대기에서는 구매 영역이 0개였고, 소니 상품에 한해 5초 대기한 두 요청에서는 구매 영역이 1개였으나 상품 선택 링크 2개가 있어 `VARIANT_UNSUPPORTED`로 보류됐다. 링크의 한글은 진단 콘솔 인코딩 문제로 정확히 읽지 못했다. 별도 로컬 브라우저에서 단일 옵션을 선택했을 때 표시 판매가와 총 상품금액은 모두 159,000원이었다. 이 관찰만으로 Firecrawl 응답에서 선택 후 금액을 검증했다고 간주하지 않는다. 5초 대기는 진단에만 사용했으며 상품은 비활성 상태다. 개발 DB의 이번 달 예약 호출은 기존 6회, 가격 worker 2회, 진단 4회로 총 12회다.

추가 진단 4회에서는 주문 버튼을 누르지 않고 단일 상품 옵션만 선택하는 Firecrawl action을 시험했다. 옵션 링크 하나는 확인됐지만 선택된 옵션은 반환된 스냅샷에 나타나지 않아 가격 판정은 계속 보류됐다. 선택 동작의 실행 여부와 스냅샷 반영 여부 중 어느 단계가 원인인지 확정하지 못했다. 실험용 action과 임시 진단 코드는 적용하지 않았다. 추가 요청을 포함한 개발 DB의 월 예약 호출은 총 16회다.

2026-10-30에는 action의 반환값을 확인하는 진단을 2회 더 실행했다. 첫 요청은 진단 클라이언트의 짧은 읽기 제한으로 시간 초과됐다. 제한을 실제 수집 클라이언트와 맞춘 두 번째 요청에서는 옵션 링크에 `click()` 호출이 이뤄졌고 후속 스냅샷 하나가 반환됐지만 선택된 옵션은 없었다. 호출 반환값은 페이지의 선택 처리 성공을 보장하지 않는다. 옵션 처리와 스냅샷 반영 중 실패 단계는 아직 확정하지 못했다. 두 요청도 월 호출 예약에 반영해 총 18회이며, 원문과 실험 코드는 보관하지 않았다.

## 소니 판매처의 플랫폼 API 검토

소니 상품 화면이 호출하는 쇼핑몰 플랫폼에는 [공식 상품·옵션 API 문서](https://docs.shopby.co.kr/?url.primaryName=product%2F)와 [호출 안내](https://workspace-help.nhn-commerce.com/aurora-guide/api/shopbyapi)가 있다. 문서는 상품 번호별 옵션 조회와 프론트 화면용 상점 식별자·플랫폼·버전 헤더를 설명한다. 공개 명세의 옵션 응답에는 할인 적용가, 추가금액과 판매 가능 상태 항목이 있다. 별도 브라우저 확인에서 Float Run은 한 옵션과 추가금액 0원, 구매가 159,000원을 반환했지만 이는 해당 시점의 단일 관측이다.

이 문서는 쇼핑몰 화면 구성에 필요한 API가 존재한다는 근거다. 소니가 제3자 서비스의 반복 조회와 데이터 재사용을 허용하는지, 적용 한도와 계약·비용이 무엇인지는 확인되지 않았다. 플랫폼 문서의 존재나 브라우저의 성공 응답만으로 사용 권한을 추정하지 않는다. 해당 API를 새 provider로 등록하거나 상점 식별자·인증 정보를 저장하지 않았으며, 소니 상품은 비활성 상태다. 향후 사용 조건과 독립적인 가격·옵션 검증을 확인한 뒤 Firecrawl DOM 방식과 유지보수·실행 비용을 비교한다.

## 2026-10-30 HT19 사양과 국내 판매처 추가 확인

QCY 한국 판매 페이지의 HT19와 제조사 MeloBuds N60 페이지의 HT19 표기 및 사양표 IPX5를 대조했다. 개발 환경에서 고정 제조사 페이지를 직접 조회한 뒤 HT19 방수의 확인 시각과 7일 뒤 다음 시도 시각이 PostgreSQL에 저장됐다. GitHub 출처 점검에서도 해당 인용이 존재했다. 최초 기동에는 빈 사양의 기존 revision에 시도가 예약되고 새 revision에 확인 시각이 남지 않았다. 등록과 예약의 정확한 선후 관계는 확인하지 못했으며, 확인 대상이 없는 경우 시도를 선점하지 않도록 변경하고 회귀 검증한다.

삼성 갤럭시 버즈 온 페이지에는 JSON-LD 299,000원과 같은 기준가가 표시됐지만 대표 가격은 카드 혜택이 반영된 최대 혜택가로 설명된다. 일반 구매가를 기존 조건부 가격 제외 규칙에 따라 확정할 근거가 부족해 등록하지 않았다. LG TONE-UT90S와 TONE-TFP9 공식 상품 페이지는 단종으로 표시됐다. 이 관측은 모든 삼성·LG 상품의 수집 가능성을 대표하지 않는다. Firecrawl 유료 호출은 추가하지 않았다.

HT19의 제조사 페이지는 동일한 HT19 표기와 `56dB ANC`를 명시해 ANC 지원 근거를 추가했다. 별도 개발 시험 DB에서 실제 페이지를 읽은 결과 HT19의 ANC·방수, T13 Pro의 ANC·호환성·방수와 Apple의 ANC·방수 확인 시각 및 각 제품의 7일 뒤 시도 시각이 저장됐다. 방수 값 불일치 시 ANC 확인과 독립적으로 처리하는 통합 테스트도 통과했다. 추가 Firecrawl 호출은 없었다.

추가 판매처 확인에서 JBL 한국 공식 사이트의 Tune Buds 2와 Wave Beam 2는 금액이 표시되지만 확인한 화면에 구매 버튼이 없고 상세 안내만 표시됐다. 표시 금액만으로 구매 가능성을 추정하지 않았다. 삼성 버즈3 FE 상품 페이지는 JSON-LD 가격과 표시 혜택가가 135,200원으로 일치했으나 카드 혜택을 포함하는 최대 혜택가 설명이 함께 있어 일반 판매가로 확정하지 않았다. 두 사이트의 모든 상품이나 다른 수집 경로에 관한 결론은 아니다.

## AirPods 5 구성별 가격과 사양 검증

Apple 한국 구매 페이지에서 기본형과 무선 충전 케이스형은 각각 199,000원과 229,000원으로 표시됐다. 무선 충전 케이스형을 선택한 페이지에서 단일 Offer SKU `MKFT4KH/A`와 해당 구성의 선택된 구매 링크·금액을 연결했다. 각인 없음 선택 후 장바구니 버튼이 활성화되는 것을 확인했으며 장바구니 추가는 수행하지 않았다. 다른 구성의 가격이나 다중 선택 상태는 거절한다.

별도 개발 시험 DB에서 실제 Firecrawl 가격 수집 1회는 229,000원 VERIFIED였고, 공식 사양 페이지를 직접 조회한 ANC·IP57 확인 시각과 다음 주 시도 시각도 저장됐다. 이는 단일 시점의 개발 검증이다. 이번 호출은 기존 개발 DB에 기록된 18회와 별도 시험 DB 1회로, 같은 계정에서 관측한 총 예약 호출은 19회다. 상품 6개의 일간 갱신은 30~31일에 180~186회가 필요하다.

## Marshall 한국 공식 스토어

공식 이어폰 목록에서 MOTIF II A.N.C. BLACK의 상품 번호 1006450을 확인했다. 개발 시험 DB에서 Firecrawl 수집 2회 중 첫 회는 관련 상품 가격 때문에 PRICE_CONTEXT_MISSING, 검증 규칙을 보완한 두 번째는 269,000원 VERIFIED였다. 공식 페이지 직접 조회로 모델·ANC 사양을 검증해 DB 확인 시각과 다음 주 시도 시각을 저장했고 읽기 전용 문구 점검도 통과했다. 단일 시점의 관측이다.

이 상품을 포함한 7개의 일간 수집에는 월 210~217회가 필요해 기존 상한 200회를 넘는다. 한도 조정이 결정되기 전에는 등록을 비활성으로 유지한다. 기존 계정의 개발 수집 19회와 별도 시험 DB의 2회를 합하면 이달 관측한 예약 호출은 21회다.

같은 시험 DB의 활성 상품과 저장된 관측을 사용해 외부 수집·AI를 끄고 추천 API를 호출했다. 이어폰, 예산 300,000원, ANC 필수, 플랫폼 미선택 요청에 `SUCCEEDED`로 응답했으며, MOTIF II A.N.C.는 269,000원 `VERIFIED`, ANC `MEETS`, `RECOMMENDED`로 표시됐다. 이 검증은 시험 DB에서만 상품을 활성화한 결과이며 기본 manifest의 비활성 상태나 월 호출 상한을 변경하지 않는다. 추가 Firecrawl 호출은 없었다.
