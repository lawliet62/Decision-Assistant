# 사용자 직접 평가표

[평가 보고서](README.md)와 [agent의 출처 검토](source-review.md)를 참고하되 아래는 사용자 평가를 남길 빈 양식이다. Agent 평가를 사용자 평가로 복사하지 않는다. [고정 15조건](../../../scripts/discovery-evaluation/cases.json)과 [공통 평가 기준](../../discovery-evaluation.md)을 사용한다.

공식 상품·가격·예산·최소 사양·기본 호환성까지 근거를 확인한 서로 다른 모델만 후보 수로 센다. 앱 OS 지원과 제품의 기본 호환성, 문서 직접 진단과 실제 검색 경로의 성과를 구분한다.

설명 점수는 0 근거 없음, 1 사양 반복·일반론, 2 확인 사양과 용도 연결, 3 연결 설명과 한계·미확인 사항 제시다. 후보가 없으면 해당 없음이다.
