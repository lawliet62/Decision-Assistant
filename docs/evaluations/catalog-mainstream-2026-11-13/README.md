# 주류 이어폰 3개 브랜드 통합 검증

Sony WF-C710N, JBL TUNE BEAM 2, Samsung 버즈4를 기존 카탈로그와 합쳤다. 각각의 branch 검사만으로 공통 manifest·파서·호환성 코드의 조합을 증명할 수 없어 변경을 통합하고 전체 검증과 실제 API 검증을 수행했다. 기존 Sony·JBL PR의 구현과 근거는 통합 변경에 보존했다.

## 현재 데이터와 실제 추천

[카탈로그 집계](catalog-summary.json)의 2026-11-13 기준 활성 제품은 25개·10개 브랜드다. 72시간 안의 검증 가격은 22개·9개 브랜드다. 이는 모든 필수 조건을 만족하는 제품 수가 아니다.

| 검증 가격대 | 제품 수 |
| --- | ---: |
| 5만원 미만 | 8 |
| 5만원 이상-15만원 미만 | 7 |
| 15만원 이상-30만원 미만 | 6 |
| 30만원 이상 | 1 |

실제 개발 DB의 공개 카탈로그 데이터만 별도 PostgreSQL에 복사하고 통합 코드를 기동했다. identity·revision·구매 URL·사양 근거가 모두 일치하는 25개 행에만 원래 가격·사양 확인 시각을 반영했다. 개인정보·결정 데이터는 복사하지 않았다. V24 schema에서 외부 AI·검색·웹 수집·가격/사양 refresh를 끄고 실제 API를 호출했다. 새 가격 조회로 시각을 연장하거나 fixture 가격을 넣지 않았다.

25만원·ANC 필수·외부 동의 false 조건에서 다음 추천을 확인했다. [API 결과 메타데이터](api-results.json)에 다른 UNKNOWN 후보와 원래 가격 확인 시각도 남겼다.

| 기본 연결 조건 | RECOMMENDED |
| --- | --- |
| Android | QCY T13 Pro 22,900원, JBL TUNE BEAM 2 99,000원, Sony WF-C710N 139,000원, Samsung 버즈4 220,200원 |
| iOS | QCY T13 Pro 22,900원, Samsung 버즈4 220,200원 |

추천 항목의 ANC·기본 연결은 모두 MEETS였다. Sony의 iPhone 표현을 iOS 별칭으로 확장하지 않았고 JBL의 iOS는 미확인으로 유지했다. 앱·고급 설정은 기본 연결과 구분한다. 확인용 임시 결정 두 건은 DELETE 204로 삭제했다. 이 API 검증 동안 외부 가격 관측은 0건이었다.

## 개별 실제 수집과 비용

- [Sony 실측](../sony-c710n-2026-11-13/README.md): 실제 139,000원 관측, 개발 Node 조회→Java 검증→사양 시각 반영.
- [JBL 실측](../jbl-tune-beam2-2026-11-13/README.md): 실제 99,000원 관측, Java 사양 갱신, 판매처를 제품 브랜드로 오인한 migration 보정.
- [Samsung 실측](../samsung-buds4-2026-11-13/README.md): 실제 220,200원 관측, 공개 즉시 할인·카드 미적용·행사 기간 검증, Java 사양 갱신.

개발 DB의 앱 월 계수는 Sony 검증 직전 48에서 최종 77로 증가했다. 신규 모델 검증 8회와 기존 제품 갱신 21회를 포함한다. 공급자 잔여 credit은 별도로 확인한 구간에서 1,020→995였으며, 이 구간은 Sony 검증 이후의 기존 제품 21회·JBL 3회·Samsung 1회다. 앱 계수와 공급자 청구를 동일시하지 않는다. 후속 실측의 OpenAI 추가 호출·구매·충전·운영 리소스 생성은 없었고 실제 청구 금액은 확인하지 않았다.

## 검증과 한계

통합 상태에서 `npm run check`를 통과했다. 단위·Node 검사, PostgreSQL 통합 98개, OpenAPI 계약, lint, typecheck, production build를 포함한다. 개별 가격/사양의 실제 외부 검증과 위 통합 API 검증을 구분했다. 원문 HTML·비밀·사용자 데이터는 저장하지 않았다.

기본 개발 DB에는 HT10 PRODUCT_MISSING, CT06의 이전 RESOLVED_URL_MISMATCH, 젠하이저 CANONICAL_URL_MISMATCH가 남아 있어 해당 가격을 추천 근거로 사용하지 않는다. CT06의 다음 실제 조회는 11월 14일 15:42 KST 이후다. Jabra와 신규 세 모델의 기존 예약도 앞당기지 않는다.

브랜드 수가 늘어도 필수 조건을 추가하면 후보 수가 줄어든다. 특히 iOS 등 플랫폼 근거의 범위를 더 보강할 여지가 있다. 실제 48시간 후 반복 갱신, 기존 실패 출처 진단, human 병합은 남아 있으므로 전체 Goal을 완료 처리하지 않는다. GitHub 출처 점검의 manifest 기준 기한과 DB의 자동 확인 시각은 별개이며 주간 외부 점검 전체가 이번 CI로 성공했다고 주장하지 않는다. 운영 배포와 상시 운영은 별도 설계 범위다.
