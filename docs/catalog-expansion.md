# 이어폰 데이터 확대와 혼합 수집 실행 기준

2026-11-13 승인된 작업 범위다. 가격 자동 갱신·사양 출처 점검·사양 갱신·국내 판매처 확대 목표를 유지하며, 무선 이어폰에서 주류 브랜드와 주요 가격대를 비교할 수 있는 데이터 확보를 완료 기준에 추가한다. 운영 배포·외부 기능 활성화는 ADR 0019의 별도 경계를 따른다.

## 완료 기준

- 기존 카탈로그의 Apple·BOSE·Marshall·젠하이저·Anker·QCY를 유지하면서, 현재 공백인 Samsung·Sony·JBL의 국내 공식 판매 제품을 조사한다. 브랜드의 시장점유율 순위를 주장하는 기준은 아니다.
- 전체 활성 30개 한도 안에서 5만원 이하, 5만~15만원, 15만~30만원, 30만원 초과의 가격대와 커널형·오픈형·이어커프 구성을 점검한다. 신규 제품은 가급적 중복 색상보다 부족한 조건을 채우는 모델로 선정한다.
- 대표 후보에는 모델·세대·구성 식별, 국내 공식 구매 출처, ANC 및 기본 호환성의 근거를 확보한다. 입증되지 않은 항목은 UNKNOWN으로 유지한다.
- 단순 브랜드 등록으로 완료하지 않는다. 주요 예산·ANC 조건에서 실제 사용 가능한 복수 후보가 나오고, 정보 확인 시각이 표시되는 것을 DB→API에서 검증한다. 확보되지 않은 가격대·형태·브랜드는 공백으로 보고한다.
- 실제 수집과 검증, 개발 환경 정기 갱신을 구분한다. 운영 활성화와 장기 안정성을 단일 실측으로 주장하지 않는다.

## 혼합 구조

1. 공식 API와 검증된 직접 HTTP 경로는 정형 가격·사양 갱신에 사용한다. CT06 직접 수집의 승인·48시간 간격은 ADR 0016을 따른다.
2. OpenAI 웹 검색은 신규 모델·누락 사양·출처 변경의 조사 제안을 만든다. 공개 상품 정보만 전달하고 사용자 조건·결정·메모는 전달하지 않는다.
3. 모델의 결과는 `PROPOSAL_UNREVIEWED`다. 카탈로그나 가격 관측을 자동 수정하지 않는다. 출처·동일 모델·옵션·가격·재고·할인 조건의 기존 검증을 거쳐야 적용한다.
4. 같은 판매처의 반복 갱신을 코드로 유지하는 비용이 에이전트보다 커지는 근거가 생기면 에이전트 경로를 권고한다. API 비용뿐 아니라 코드 수정·실패 진단·검토 시간을 함께 비교한다.

## 첫 OpenAI 비교 조사

개발 `local` 프로필에서 `DECISION_ASSISTANT_CATALOG_RESEARCH_ENABLED=true`, `DECISION_ASSISTANT_CATALOG_RESEARCH_TASK=SAMSUNG`을 명시하면 시작 시 한 과제만 실행한다. 기본은 비활성이고 운영 프로필에는 실행기가 없다. DB와 기존 Dev Secret Manager의 `openai-api-key`를 사용하며 AI·Firecrawl·검색·메일·가격/사양 refresh를 별도로 켤 필요가 없다.

고정 과제는 SAMSUNG, SONY, JBL, QCY, ANKER다. UTC 월별 실행 슬롯 1~5를 한 번씩만 예약하며 최대 5회다. `DECISION_ASSISTANT_CATALOG_RESEARCH_SLOT`을 명시한다. 실패 슬롯은 재사용하지 않으며 다음 과제를 실행하려면 다른 미사용 슬롯을 명시해야 한다. 모델은 웹 검색 지원을 확인한 `gpt-5.4-mini-2026-03-17`, 최대 도구 호출 3회·출력 4,000토큰·자동 재시도 없음으로 제한한다. 모델 context와 도구 상한을 고려해 과제당 $1, 최초 비교 조사 전체 $5를 보수적인 예약 예산으로 잡는다. 이는 월 $100 크레딧 전체를 사용하는 승인이나 계정 전체의 과금 차단 기능이 아니다. 모델/도구 가격 변경과 실제 사용량을 확인하고, 실패·타임아웃으로 사용량을 모르면 예약을 되돌리지 않는다. 실제 API 호출 전 계정의 유효 크레딧·현재 공개 단가와 실행 설정을 확인한다.

반환한 token·검색 수와 출처, 짧은 조사 제안을 DB에 남긴다. provider·모델·prompt 버전과 요청 상한도 기록한다. raw API 응답·API 키·페이지 원문은 저장하지 않는다. 모델의 수집 시각이 출처의 갱신 시각을 보증하지 않는다. 공식 도메인 밖의 출처, 출처 없는 응답, 검색·사용량이 없는 응답은 실패로 처리한다.

## 미완료 항목

첫 Samsung·Sony·JBL 실행은 [평가 기록](evaluations/catalog-research-2026-11-13/README.md)에 남겼다. JBL만 미확인 제안을 반환했고 나머지 두 건은 실패 또는 사용량 미확인이다. 실제 신규 등록과 수집 정확성 검증은 남아 있다.

Samsung·Sony·JBL의 검증된 신규 등록, 가격·사양 근거 보강, 복수 후보 추천 및 반복 갱신은 아직 완료되지 않았다. 첫 조사 이후 정확도·비용·유지보수량을 보고 다음 배치를 정한다. Jabra와 CT06의 이미 예약된 실제 재조회 간격을 단축하지 않는다.
