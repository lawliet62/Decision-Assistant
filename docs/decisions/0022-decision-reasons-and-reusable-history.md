# 결정 이유·구매 상태·다음 결정에서의 기록 활용

- 상태: Accepted
- 날짜: 2026-11-17
- 승인: 이유 템플릿과 자유 입력, 보류를 포함한 결정 완료, 구매 전 재검토·취소, AI 없는 과거 기록 활용에 대한 명시적 승인

## 동작과 경계

진행 중은 DRAFT다. 제품 선택(CHOSEN), 보류(DEFERRED), 포기(ABANDONED)는 모두 완료다. 기존 status를 보존하고 phase 및 목록 분류를 변경한다. 기존 보류 기록도 완료로 표시하며 직접 편집하려면 다시 검토한다. 과거 이유나 구매 여부를 추정해서 채우지 않는다.

결과별 이유 템플릿을 여러 개 선택하고, 대표 이유 하나와 자유 메모를 선택적으로 남긴다. 이유가 없어도 완료할 수 있다. 이유는 사용자 판단이며 ProductFact·조건 판정이나 평가 가중치를 자동 변경하지 않는다. 템플릿 ID는 기존 의미를 유지하며 미래 템플릿 확장은 새 ID로 추가한다.

제품 선택은 구매와 별개다. 선택 기록에 구매 미기록·구매 예정·구매함·구매하지 않기로 함을 기록한다. 기록하지 않음은 미구매의 증명이 아니다. 구매함은 이후 변경·재검토를 막는다. 반품·환불은 범위 밖이다. 구매 기록은 최신 결정 version과 resolution ID를 확인한다.

구매하지 않았음을 명시적으로 확인하면 선택·보류·포기 모두 정정 또는 재검토할 수 있다. 이전 이유·근거·회고를 보존하며 기존 정정의 superseded 의미를 유지한다. 시작 전 draft를 임시 JSONB로 보존하고 취소 시 복원한다. 새 결론이 완료되면 임시 복원본을 해제한다. 이전 버전에서 시작한 재검토는 복원본이 없으므로 취소 복원은 제공할 수 없다. 완료 전후 동시 요청은 부모 결정 잠금과 version으로 검사한다.

정정 모드에서는 `revisionBaseId`가 가리키는 기록의 결과·선택 제품·이유 목록·대표 이유·메모를 입력 초기값으로 사용한다. 제목·비교 값만 정정해도 기존 판단을 다시 입력하지 않는다. 일반 재검토의 새 판단 입력과 구분한다.

취소 복원본에는 추천 후보별 수락·제외 상태와 제품 연결도 포함한다. 기존 수락·제외는 시작 전 그대로 복원하고, 검토 중 새로 생긴 추천 후보는 제안 상태로 남긴다. 추천 실행 묶음과 수집 자료 자체를 삭제하거나 되돌리지 않는다. 이전 버전에서 시작해 후보 상태 복원본만 없는 경우 끊긴 수락 연결을 제안으로 되돌리는 보수적인 복구만 수행한다.

필수 흐름은 결정 완료로 끝난다. 구매 기록·회고는 선택 사항이며 새 완료에 자동 회고 알림을 예약하지 않는다. 기존 예약은 기존 운영 경계를 유지하며 재검토 시작 시 중단한다.

## 기록 활용

새 결정에서 같은 제품군의 최근 유효한 완료 기록 최대 3개와 각 기록의 최근 회고 최대 2개를 보여준다. 제품·결과·이유·자유 메모·회고를 원문으로 표시하며 출처 결정 링크를 제공한다. 제품 선택에서 만족했을 것이라고 추정하지 않는다. 사용자가 ‘이번에도 참고’를 선택하면 출처 ID를 포함한 참고 메모를 현재 draft에 추가하고 저장할 수 있다. ‘이번에는 다름’은 이번 화면에서만 표시하며 고정 취향을 생성하지 않는다.

동일 소유자만 조회할 수 있으며 삭제·개인화 활용 해제·정정된 과거 기록·정정 진행 중 원본은 제외한다. 보관함 기록은 기존 활용 설정에 따른다. 다른 제품군으로 전이하거나 평가 가중치를 자동 적용하지 않는다. 외부 AI 호출·임베딩·요약·새 provider는 도입하지 않는다. 긴 자유 메모는 원문 그대로 활용하며 AI의 추가 가치는 후속 검증 대상이다.

## 대안과 검증

완료 기록을 덮어쓰는 방식은 단순하지만 판단 변화의 경위가 사라진다. 기존 Resolution 이력을 확장하여 이유와 구매 상태를 귀속하고 재검토 이전 기록을 보존한다. 새 상태 체계를 전면 교체하면 호환 API와 운영 데이터 변경이 커지므로 기존 enum을 유지한다.

`DecisionApiIntegrationTest`는 이유 validation·미구매 확인·구매 후 차단·취소·기록 활용 ownership을 검증한다. 브라우저 검증은 이유 GUI·메모·완료·구매·재검토와 선택적인 회고를 포함한다. 사용자 편의성 효과와 기억의 유용성은 실제 사용자 평가 전까지 미검증이다.
