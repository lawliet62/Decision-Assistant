# 결정별 요약과 현재 조건에 따른 과거 이유 설명

- 상태: Accepted
- 날짜: 2026-11-17
- 승인: 사용자가 결정별 요약과 현재 결정에 관련된 과거 이유 설명의 첫 구현 범위를 수락하고 구현을 요청함

## 동작

같은 제품군의 최근 유효한 기록 최대 3개를 보여주는 기존 기록 참조에서, 각 기록의 선택적인 AI 요약과 현재 조건에 따른 참고 설명을 제공한다. 결정 완료에 필요한 단계는 추가하지 않는다. 요약은 하나의 원본에 명시된 이유·구매 상태·회고를 대상으로 하며, 반복되는 경향이나 고정 성향을 생성하지 않는다. 선택 사실만으로 구매·사용 만족을 추정하지 않는다. 현재 제품의 호환성이나 사양을 과거 판단으로 확정하지 않는다.

AI에는 현재 제목·용도·예산·비교 조건과 해당 원본의 제목·결과·이유·대표 이유·메모·구매 상태·당시 조건·최근 회고를 전송한다. 전송 내용을 화면에서 확인할 수 있으며 매 생성 요청에 명시적인 외부 전송 동의와 민감정보 미포함 확인이 필요하다. 현재 메모는 복사한 AI 해석의 재사용을 피하기 위해 보내지 않는다. 기존 OpenAI/Gemini 설정과 timeout을 사용하며 새 provider나 자동 실행은 추가하지 않는다. Gemini 무료 티어 고지도 유지한다.

결과는 당시 결정 요약, 이번 결정과의 조건부 관련성, 적용 조건, 불확실성으로 나누고 AI 해석임을 표시한다. 원문 결정 링크를 함께 제공한다. 사용자는 ‘이번에도 중요함’, ‘이번에는 해당 없음’, ‘해석 수정’을 선택한다. 확인·수정 내용은 출처 ID와 함께 현재 메모에 추가하고 기존 변경 저장으로 보존한다. 해당 없음은 이번 화면에만 적용한다. 어느 동작도 장기 선호 확인이나 가중치 변경으로 연결하지 않는다. 기존 회고 기반 성향 기억은 별도 기능으로 유지한다.

기본·기존 편집기에서 미저장 변경이 있으면 AI 해석 생성과 확인·수정 내용 적용을 비활성화하고 먼저 저장하도록 안내한다. 비교 조건 편집도 같은 경계를 따른다. 저장 후 갱신된 version으로 전송 입력과 저장 결과를 다시 조회하여 화면 조건과 저장된 조건이 어긋난 해석을 적용하지 않는다.

## 저장·수명과 동시 변경

요약과 설명은 현재 결정·원본 결정·원본 resolution에 연결해 저장한다. 입력 hash, provider/model, prompt/schema version, latency, token 수와 생성 시각을 기록한다. 기존 AI 경계에 따라 동의한 입력 snapshot을 호출 전에 저장하며 원본 전체가 아닌 실제 전송 항목만 고정한다. 실패한 호출의 입력도 동일 부모 수명을 따르고, 원본 또는 현재 결정의 영구 삭제 시 snapshot과 결과를 함께 제거한다. 동일 입력의 저장 결과는 재사용하며 재접속 시 다시 호출하지 않는다.

원본이 삭제·활용 해제·정정 중·정정된 상태이거나 최근 기록 범위에서 벗어나면 조회·생성 대상에서 제외한다. 현재 입력이나 원본 이유·구매·회고가 바뀌면 이전 hash의 결과를 표시하지 않는다. 원본 또는 현재 결정이 영구 삭제되면 외래 키 cascade로 연결된 해석도 삭제한다. 다른 결정의 메모에 사용자가 이미 복사한 내용은 기존 복사값 정책을 따른다.

외부 호출 전 확인한 hash와 실제 입력이 다르면 전송하지 않고 409를 반환한다. 호출 중에는 DB 잠금을 보유하지 않는다. 결과 저장 직전에 두 부모 결정을 ID 순으로 잠그고 최신 원본 자격과 입력 hash를 재확인한다. 삭제·활용 중단·정정·입력 변경 뒤 도착한 결과는 저장하지 않는다. 실패 시 원문 참조를 계속 제공하며 자동 재시도하지 않는다.

## 검증과 한계

실제 PostgreSQL 통합 검증으로 동의·소유권·동일 입력 재사용·입력 변경·활용 해제·외부 호출 중 삭제·파생 기록 cascade·출력 형식·provider 실패를 확인한다. 브라우저 검증은 전송 확인과 요약 표시·조건 확인·사용자 수정·원본 링크·메모 저장을 확인한다. 테스트의 AI 응답은 가상 자료이며 실제 유료 호출과 모델 품질 평가는 수행하지 않는다. 의미 왜곡과 실사용 편의성은 후속 사용자 평가가 필요하다. 여러 기록의 경향 분석, 모델 학습, 자동 가중치 적용은 이번 범위 밖이다.
