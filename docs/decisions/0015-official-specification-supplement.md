# ADR 0015: 동일 모델 공식 문서의 제한적 사양 보완

- Status: Accepted
- Date: 2026-10-06
- Decision: human이 가격 검증 후보 최대 2개의 공식 문서 보완, 실행당 검색 3회·수집 7페이지·AI 1회 및 같은 15조건 실제 평가를 승인했다.

## 문제와 결정

[상품 연결 복구 평가](../evaluations/discovery-linking-2026-10-01/README.md)는 가격 확인 후보 7개를 반환했지만 모두 필수 사양·호환성이 미확인이었다. 구매 페이지에 없는 사양을 같은 모델의 공식 제품·지원 문서에서 제한적으로 보완한다. 구매 후보 발견과 가격 검증은 기존 국내 공식 판매처 기준을 유지한다.

- 신규 입력에서 `officialEvidenceConsent=true`를 별도로 선택한 요청만 `official-kr-v3`를 사용한다. 기존 동의만 있는 요청·재시도·추가 탐색은 v2와 검색 1·수집 5·AI 1을 유지한다. 저장된 조건에 보완 동의를 소급하지 않는다.
- 최초 상품 검색·수집 뒤 가격을 검증한 서로 다른 모델을 판매가 순으로 확인한다. 선택한 필수 사양·호환성이 UNKNOWN이고 등록된 모델 식별이 가능할 때 최대 2개를 보완한다. 각 모델에 검색 1회, 그 결과 중 공식 문서 1페이지 수집만 허용한다. 총 상한은 검색 3·수집 7·AI 1이다. Serper의 월별·사용자별 기존 quota를 공유하고 자동 재시도하지 않는다.
- 보완 검색에는 구매 페이지의 공개 모델 코드와 공식 문서 검색 범위만 보낸다. 메모·개인 identity·사용자 입력 제품명을 추가하지 않는다. 검색 제목·snippet은 근거가 아니다.
- 문서 호스트·경로를 별도 등록한다. 요청·최종·canonical URL과 문서 본문의 단일 모델 표기를 대조한다. T13/T13 ANC/T13 ANC 2, 다른 구성, 지역 모델 별칭을 추정해서 합치지 않는다. 구매 가격·이미지는 보완 문서로 대체하지 않는다.
- 표·항목 목록·확인한 QCY 사양 블록의 명시적 값만 서버가 채택한다. 앱 OS나 Bluetooth 버전은 기본 플랫폼 호환성의 대체물이 아니다. 문서의 설명 문장 전체를 AI에 추가 전송하지 않는다. 기존 상품 구조화 AI 한 번과 서버의 최종 설명 구성을 유지한다.
- 보완 사양은 URL·짧은 인용·조회 시각, 구매/문서의 모델 인용과 근거 영역 SHA-256을 보존한다. `UNREVIEWED`를 유지하고 기존 사양과 상충하면 UNKNOWN이다. 전체 HTML·문서·이미지는 저장하지 않는다.
- 보완 provider 실패는 확보한 상품을 유지한 PARTIAL로 처리한다. 공식 문서나 사양을 찾지 못한 경우에는 미확인 사양을 유지한다. 계정·burst 한도는 다음 보완 요청도 중단한다.

## 초기 등록과 제한

직전 평가에서 가격 검증을 통과한 모델이 QCY였으므로 실제 구조를 확인한 QCY 공식 제품·지원 문서를 우선 등록한다. [등록 범위](../official-stores.md#공식-문서-사양-보완)를 따른다. 다른 브랜드, 구별 가능한 모델 코드가 없는 제품, HT16/MeloBuds N50 같은 지역 별칭은 자동 연결하지 않는다. 검색 상한 증가는 후보·정확도 향상의 보장이 아니며 가격 확인 후보가 없는 조건을 해결하지 않는다.

OCR·PDF 파서·리뷰 수집·범용 탐색 agent·새 provider는 도입하지 않는다. 이 변경은 ADR 0011/0013/0014의 호출 상한과 상품 페이지 한정 사양 출처를 보완 동의가 있는 실행에 한해 확장한다. 가격·필수 조건 판정과 과거 결과의 의미는 유지한다. API에는 선택적 동의와 사양별 모델 연결 근거를 추가하며 JSONB 기존 값은 null로 읽는다. migration/backfill은 없다.

## 검증

동일 모델·세대/구성 불일치·관련 상품 오염·리다이렉트·앱 전용 지원·상충·미동의·2모델 상한을 unit/API/browser 테스트로 확인한다. 기존 15조건을 고정 빌드로 한 번씩 실행하며 총 상한은 검색 45·수집 105·AI 15이다. 계정 한도나 실패도 보고하고 성공 사례만 재실행하지 않는다. 실제 추천 확보와 parser fixture 성공을 별도로 평가한다.
