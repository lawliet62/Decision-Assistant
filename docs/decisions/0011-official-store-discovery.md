# ADR 0011: 공식 판매처 중심 추천과 같은 조건의 추가 탐색

- Status: Accepted
- Date: 2026-09-24
- Decision: human이 도그푸딩 개선 계획과 홈·입력·결과의 공통 안내를 승인했다. 진단·수집 개선, 공식 판매처 추천, 추가 탐색 순서로 구현한다.

## 결정

- 국내·한국어 공식 판매처에서 제품과 정확한 원화 판매가를 확인한 후보를 추천한다. 제조사 스토어와 확인한 공식 브랜드몰의 도메인·판매자 경로를 관리하며 공식 여부를 AI 판단에 맡기지 않는다.
- 검색 1회·수집 최대 5개·AI 최대 1회를 유지한다. 공식 페이지부터 탐색하며 공식 링크·비교 가능한 가격이 없는 후보는 제외한다. 전체 시장·최저가·재고·제품 안전성 보증은 제공하지 않는다.
- 최소 조건과 예산을 충족한 후보는 확인한 판매가 오름차순으로 표시한다. 조건 미확인과 미달은 별도 참고 영역에 보존한다. 가격에는 조회 시점과 배송비 제외 기준을 표시한다.
- 공식 판매 페이지의 제품 이미지는 확인된 이미지 주소로 브라우저가 직접 요청한다. referrer를 보내지 않지만 이미지 서버에는 IP가 전달된다. 누락·오류 시 대체 이미지를 사용하고 서버 중계·캐시는 만들지 않는다.
- 공식 판매처 기준과 다른 판매·할인 경로가 더 저렴할 수 있다는 안내를 홈·조건 입력·결과에 표시한다. 정책이 실제 적용된 실행만 공식 판매처 추천으로 표시하며 과거 결과와 직접 추가 제품에는 소급하지 않는다.
- 같은 Decision에서 같은 조건으로 새 추천 묶음을 요청할 수 있다. 이전 추천 모델·구성을 누적 제외하고 승인한 제품·입력은 유지한다. 실패 복구와 추가 탐색은 다른 동작이며 자동 재검색은 하지 않는다.
- 추천은 전용 scheduler에서 한 번에 1건 처리하고 페이지는 최대 2개씩 병렬 수집한다. 실패한 페이지와 성공한 근거를 분리하고 시간·개수·고정된 탈락 사유만 관측한다.
- 페이지 예산 안에서 사양 관련 블록을 선택한다. 제품명이 제목에 있는 동일 블록의 정확한 사양 인용을 허용한다. 다른 제품의 섹션·상충·불명확한 지원 표현을 임의로 합치지 않는다. 자동 사양은 UNREVIEWED를 유지한다.

## 영향

ADR 0009의 순서 무의미·실패 시에만 재실행 경계와 ADR 0010의 UNKNOWN 기본 목록 정책을 승인된 범위에서 변경한다. 원문 전체 저장·외부 추가 provider·전체 시장 카탈로그·영상 타임스탬프·자동 번역은 도입하지 않는다. 실행마다 기존 호출 상한·소유권·동의·quota를 유지하며 API와 저장 구조는 기존 자료를 읽을 수 있도록 확장한다.

공식 사이트 제한과 가격 필수 조건은 추천 수와 브랜드 범위를 줄일 수 있다. 제품을 억지로 채우거나 조건을 자동 완화하지 않는다. 실제 provider 품질·속도는 fixture 검증과 구분해 측정한다.
