# ADR 0019: 지출 승인 없는 초대형 MVP 배포 준비

- 상태: Accepted (구조·정책), 실제 운영 배포 미승인
- 날짜: 2026-11-09
- 승인: human이 단일 GCP VM, 추가 지출 0원, 백업 7일·로그 14일, 초기 기능 범위를 선택

## 결정

하나의 GCP VM에서 Next.js·Spring Boot·PostgreSQL·HTTPS proxy를 운영하는 설정을 준비한다. 기존 단일 인스턴스의 예약 작업을 유지하고 관리형 DB·queue·별도 배포 모듈은 추가하지 않는다. 운영자는 프로젝트 소유자 본인이다. 실제 자원 생성과 배포는 이번 작업에 포함하지 않는다.

최초 공개 범위는 초대된 사용자, 등록 이어폰 카탈로그와 직접 비교다. AI·실시간 검색/수집·메일·가격 및 사양 갱신은 비활성이다. 가격 갱신은 별도 호출 예산 승인 후 활성화한다. 가격이 없거나 만료되면 확인 필요로 표시하며 확인된 가격 추천이라고 주장하지 않는다.

추가 유료 지출 승인액은 월 0원이다. 무료 할당량과 기존 크레딧의 실제 적용·만료를 확인한다. 크레딧 존재나 비용 차단을 추정하지 않는다. 무료 VM이 메모리·운영 요구를 충족하지 못하면 측정과 최소 비용안을 보고하고 실제 자원 생성은 보류한다. 무료화를 위해 인증·백업·핵심 기능을 약화하지 않는다.

## 신뢰·보존 경계

운영은 Auth0와 기존 Prod Secret Manager를 사용한다. VM attached Identity로 runtime bootstrap을 수행한다. PostgreSQL 초기 role 비밀번호도 Secret Manager에서 직접 조회해 stdin으로 설정하고 평문 파일/환경변수에 export하지 않는다. API는 DB에 필요한 비밀번호를 기존 JVM 로더로 읽는다. 같은 VM의 컨테이너는 Identity 격리 경계가 아님을 운영 문서에 명시한다.

DB는 매일 별도 비공개 저장소에 백업하고 7일 보존 후 lifecycle 만료 처리한다. 운영 로그는 외부 제한된 로그 저장소에 14일 보존한다. 삭제 audit에는 UUID·시각만 남긴다. 백업·로그의 실제 저장소 설정과 복원 검증은 배포 전 필수다. Compose 로컬 로그 rotation을 14일 보존 검증으로 대체하지 않는다.

## 대안과 결과

상시 Cloud Run + Cloud SQL은 관리 부담을 줄이지만 비용과 연결 설정이 늘어난다. 현재는 선택하지 않았다. 무료 서버의 메모리가 부족하다고 기능을 삭제하거나 자동으로 다른 provider로 이동하지 않는다. 소형 VM에서는 빌드하지 않고 검증한 이미지를 외부 개발/CI 환경에서 만들어 배포한다.

준비 자산은 [deploy](../../deploy/README.md), 사양·비용·검증 근거는 [준비 보고서](../mvp-readiness.md)에 둔다. 구성 검증·로컬 smoke·CI 통과와 실제 운영 배포 성공을 구분한다.
