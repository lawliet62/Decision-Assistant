# ADR 0014: 상품 근거·호환성 판정과 설명의 일치

- Status: Accepted
- Date: 2026-09-30
- Decision: human이 실제 A안 평가의 후속 개선을 승인했다. 검색 1·수집 최대 5·AI 최대 1을 유지하며 검증 결과로 설명을 구성하고 필요한 호환성을 기본 추천의 필수 조건에 포함한다.

## 배경

실제 평가에서 JSON-LD의 회원 가격 수용, 기본 RAM·SSD 누락, 이미지 사양 미확인, 조건 판정과 AI 설명의 모순을 확인했다. 사양의 문자열 존재 검사는 의미 검증이 아니며, 공식 판매처 확인도 모든 가격·사양·용도 주장의 보증이 아니다.

## 결정

- `official-kr-v2`는 동일 수집 응답의 JSON-LD 가격과 상품 구매 영역의 라벨·금액을 대조한다. 회원·쿠폰·카드·구독 조건, 본문 가격 연결 불명확은 제외한다. 다른 표시 가격으로 대체하지 않는다. 일반 회원 안내와 별도 할인가는 해당 금액에 연결된 가격 조건과 구분한다.
- 같은 상품의 구조화 속성, 상품 microdata 내부의 표·항목 목록, 확인된 LG/QCY 상품 영역을 근거 블록으로 연결한다. 페이지 전체·다른 구성·리뷰·추천 상품을 같은 모델의 근거로 승격하지 않는다. 원문 인용과 별도로 제품·블록 식별자를 사용하며 AI가 식별자를 지정해도 서버가 다시 대조한다.
- 기본 사양은 서버도 추출한다. 항목에 있는 단위와 값, 기본 장착량과 확장 슬롯을 구분한다. 정규화 근거는 `ProductFact.normalizationVersion=basic-spec-v1`과 원문 인용으로 보존한다. 이 표시는 사람이 확인한 `CONFIRMED`를 뜻하지 않는다. 최대치·옵션·상충은 여전히 UNKNOWN이다.
- AI는 후보·사양 추출에만 사용한다. 최종 가격·사양·최소 조건·호환성 판정을 입력으로 서버가 설명을 구성한다. 미달·미확인부터 설명하며 용도와 기능의 관계를 실제 품질·만족도 보장으로 바꾸지 않는다.
- 선택한 호환성이 미확인이면 UNKNOWN, 명시적 불일치면 BELOW다. 노트북·휴대폰·태블릿은 제공 OS, 모니터는 영상 입력 연결, 이어폰은 기본 연결·음악·통화의 해당 플랫폼 지원을 확인한다. 앱의 최소 OS나 Bluetooth 버전만으로 기본 플랫폼 호환을 확정하지 않는다. 구체 장치 버전은 입력받지 않으므로 출처의 최소 버전·제약을 함께 보여주며 모든 기기 지원을 보장하지 않는다.
- 이어폰 전용 앱·기기별 추가 기능은 근거와 제한을 별도 사양으로 제공한다. 기종 선택이나 ‘강력한 전용 기능’ 옵션은 후속 과제로 기록한다. 의미가 다른 기능을 하나의 점수로 합치지 않는다.
- 기존 후보의 정책·설명·인용을 변경하지 않는다. v1의 추천 분류는 기존 의미를 유지하며 화면에서 과거 기준임을 표시한다. 새 실행에 v2를 적용하며 이미 승인·제외한 후보의 재시도 보호도 유지한다.

## 영향과 대안

ADR 0010·0011의 제품명 포함 인용/제목만으로 연결하던 근거 범위를 명시적인 상품 사양 구조까지 확장한다. 기본 추천에는 호환성 판정도 반영한다. 기존 호출·동의·공식 판매처 범위와 원문 비저장 원칙을 유지한다. 추가 AI 설명 호출이나 OCR·범용 크롤러·리뷰 수집 대신 작은 서버 규칙과 회귀 테스트를 선택했다.

본문 구매 영역을 확인하지 못하면 JSON-LD가 있어도 제외하므로 후보 수가 줄 수 있다. 사이트별 구조 변화는 미확인으로 드러나며 자동 가격 대체나 검증 완화로 가리지 않는다. v2는 전체 시장의 정확성을 보장하는 인증이 아니다.

응답에는 선택적 `compatibilityCheck`, 사양에는 선택적 `normalizationVersion`을 추가한다. JSONB의 기존 값은 null로 읽으며 schema migration이나 backfill은 필요하지 않다. 검증은 실제 형태를 축약한 fixture, API/브라우저 흐름과 동일 15조건의 별도 실제 평가로 수행한다.
