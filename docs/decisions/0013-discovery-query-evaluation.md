# ADR 0013: 간결한 후보 검색과 실제 provider 비교 평가

- Status: Accepted
- Date: 2026-09-30
- Decision: human이 A안 구현과 5개 제품군·15개 조건의 변경 전후 실제 평가 계획을 승인했다.

## 결정

조건 문구를 모두 연결한 검색이 후보 발견 단계에서 결과를 없애는 문제를 먼저 개선한다. 검색어는 기존 공식 판매처 범위·제품군과 명시적 ANC/전용 펜 지원 힌트만 사용한다. 용도·예산·호환성·숫자형 최소 조건은 검색어에 나열하지 않고 전체 조건을 기존 AI 입력과 서버 판정에 보존한다. 이 분리는 사용자 조건의 완화가 아니다.

ADR 0009/0010의 선택 조건을 검색에 포함하는 방식을 위 후보 발견 전략으로 구체화한다. ADR 0011의 공식 상품·가격 검증, 검색 1회·수집 최대 5개·AI 최대 1회, 명시적 추가 탐색과 데이터 경계는 유지한다. `NO_NEW_PRODUCTS`는 실제 이전 후보 제외에 적용하고 원래 검색이 비었으면 `NO_OFFICIAL_RESULTS`로 안내한다.

공통 계측으로 기존 방식 15회와 A안 15회를 비교한다. 모형 응답 테스트와 실제 provider 품질 평가는 구분한다. 최종 후보 수뿐 아니라 검색·수집·상품/가격 검증·사양 판정의 탈락, 시간·호출·token·계정 한도를 측정한다. 에이전트의 출처 검토와 human 평가란을 분리하며 주관적 사용 성능을 시험한 것처럼 주장하지 않는다.

## 영향과 보류

검색어가 넓어져 조건 미달·다른 제품군·중복 색상 페이지가 상위 결과를 차지할 수 있다. 공식 등록 범위와 가격 파서는 별도의 병목으로 남는다. 상한을 늘리거나 검증을 약화해 평가 결과를 개선하지 않는다.

AI 검색 계획(B), 일반 웹에서 후보 발견 후 공식 검증(C), 리뷰 분석은 이번 변경에서 구현하지 않는다. 검색 4회·수집 6개·AI 3회·120초는 후속 비교 실험의 후보 시작값이며 확정 운영 정책이 아니다. 이번 A 평가에서는 120초 초과를 관찰만 한다. 새 provider·배포 단위·범용 agent framework를 추가하지 않는다.
