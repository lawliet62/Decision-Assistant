# Product scope

## 문제 정의

Decision Assistant는 용도·예산을 선택해 개인 전자기기 후보를 찾고 주요 정보를 직접 비교하는 구매 결정 도구다. 사용자의 선택과 사후 결과를 연결하며, 점수 평가는 선택 기능으로 제공한다.

현재 개발의 우선 목적은 취업 포트폴리오다. MVP는 조건 입력부터 근거 기반 사양 비교까지의 일관된 흐름과 테스트 가능한 불확실성·비용 경계를 보여주는 데 집중한다. 실제 시장 전체의 검색 품질이나 상용 운영 완성을 뜻하지 않는다.

## MVP boundary

지원한다.

- 단일 사용자의 개인 전자기기(Laptop, Phone, Tablet, Monitor, 완전 무선 이어폰)의 후보 없는 추천 시작, 1~5개 후보 저장과 2~5개 Option 비교
- 초대된 사용자의 Google 또는 이메일 OTP 로그인과 개인별 데이터 격리
- Criterion weight와 numeric/rating value
- hard Constraint와 불확실성 표시
- 제품군 → 용도·최대 예산·호환성 클릭 → 최대 5개 추천 후보 → 주요 정보 비교. 자유 메모는 선택이며 제품명 검색·공개 URL 직접 입력도 지원
- 제품군별 객관적 최소 사양 선택, 수집 사양상 충족·미달·확인 필요 표시와 미달 후보 분리. 미달 제품도 사용자가 비교에 추가할 수 있다.
- 사용자 동의 후 공개 페이지 수집과 최대 3개의 대안 후보 제안
- 불완전 입력의 잠정 조언과 완전한 입력의 재현 가능한 평가
- 회고 reminder와 사용자가 확인·수정·삭제하는 category별 성향 기억
- 재현 가능한 algorithm result와 독립적인 LLM assessment
- 최종 선택·보류·포기와 여러 outcome check-in

지원하지 않는다.

- 협업, 공개 공유, 관리자용 사용자 관리 UI
- 인증 페이지 crawling, 지속적인 가격/재고 감시, 최저가 보장, domain catalog
- pairwise comparison, 확률 모델, 숨은 가중치 변경이나 자동 학습 모델
- 범용 대화형 agent와 사용자 확인값을 덮어쓰는 LLM 변경
- CPU 벤치마크·음질 하한·배터리 사용 조건의 자동 판정과 최소 사양의 점수 평가 연동은 후속 과제다. 기존 점수 평가 기능은 유지한다.

## 핵심 가설과 성공 신호

대상은 제품명을 아직 모르거나 여러 제품의 차이를 직접 확인하려는 개인 전자기기 구매자다. 타이핑 없이 추천과 비교에 도달하도록 하고 출처가 있는 주요 정보를 먼저 보여준다. 검색 결과는 최대 5개이고 정확한 제품·세대·페이지는 사용자가 선택한다. 첫 잠정 조언까지 필요한 시간과 답변 수, 실제 선택·outcome 기록이 핵심 신호다. 추천 클릭률만으로 correctness를 판단하지 않는다.

클릭 중심 추천 확장은 ADR 0009의 human 승인에 따라 기존 마지막 MVP 범위를 변경한다. 전체 시장을 망라하는 최적 후보 탐색, 가격·재고·공식 유통 정확성, 후기 aggregation, catalog/entity resolution subsystem, preference learning, evaluator 교체, 모바일 앱·협업·실시간 알림은 추가하지 않는다.

## 제품 원칙

- 모르는 값은 중립값으로 숨기지 않고 평가를 막거나 estimated로 표시한다.
- Constraint 위반 후보와 점수 차이의 근거를 노출한다.
- Algorithm과 LLM이 불일치할 수 있으며 이를 숨기지 않는다.
- AI proposal은 출처가 있는 미확인 draft가 될 수 있지만 사용자 확인 사실이나 실제 선택을 자동 변경하지 않는다.
- 웹·AI 추출값은 출처와 `UNREVIEWED` 상태로 저장할 수 있지만 사용자 확인값으로 취급하지 않는다.
- 질문은 모든 빈칸이 아니라 결론을 바꿀 수 있는 정보부터 최대 3개씩 제시한다.
